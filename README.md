## Description
Expense Tracker is a frontend web application built for my CS50x Final Project. 
The goal was to create a simple tool to help users track and visualize their daily expenses directly in the browser.

All data is stored in the browser using `localStorage`, so no backend or database is required. The app allows users to add expenses, categorize them, delete them, and see a live updating Pie Chart of their spending.

This project focuses on HTML, CSS, and JavaScript, with Chart.js used for data visualization.

## Features
- **Add Expenses**: Enter item name, amount, and select a category
- **Categories**: Food, Education, Travel, Other
- **Data Visualization**: Live updating Pie Chart using Chart.js
- **Total Spending**: Automatically calculates and displays total amount
- **Delete Expenses**: Remove any expense with one click
- **Filter**: View expenses from the Last 30 Days
- **Data Persistence**: Uses `localStorage` to save data in the browser
- **Responsive Design**: Works on both mobile and desktop

## Technologies
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Chart.js for charts
- localStorage for data storage
